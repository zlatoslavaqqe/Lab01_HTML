Для практики я використовую мову Python (наприклад, формула H2O чи x2 легко обчислюється в коді).

Програмування

Нижче наведено невеликий приклад програми мовою Python, яка вітає користувача та перевіряє його вік: 

name = input("Введіть ім'я: ")
age = int(input("Введіть вік: "))

print("Привіт,", name)

if age >= 18:
    print("Ви повнолітній")
else:
    print("Ви неповнолітній")

for i in range(1, 4):
    print("Крок", i)
